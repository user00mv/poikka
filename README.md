# POIKKA – náhled e-shopu

Statický náhled webu pro klientku. Objednávky nejdou odeslat, košík funguje jen v prohlížeči.

## Zveřejnění na GitHub Pages
1. Nahraj obsah této složky do kořene repozitáře (včetně souboru `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch*, větev `main`, složka `/ (root)`.
3. Za minutu je web na `https://<uživatel>.github.io/<repozitář>/`.

Stránky: `index.html` (homepage), `rostouci-overal.html`, `novorozenecky-set.html`, `info.html`.
Texty, ceny, velikosti a recenze jsou pracovní.
